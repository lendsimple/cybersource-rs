# cybersource

Idiomatic Rust client for the [Cybersource REST API](https://developer.cybersource.com/api-reference-assets/index.html),
with async, blocking and WebAssembly support.

**Status:** early development. See [`implementation.md`](implementation.md) for the design and roadmap.
